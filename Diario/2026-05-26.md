## Aprendizados da sessão 2

- Diagnostic strip com fonte < 9px é ilegível — mínimo 11px em contexto de dashboard escuro
- Coluna de investimento por canal é crítica para a conversa de headroom (quanto dá para escalar Verve?) — não remover de dashboards de pacing
- Pizza + barras Budget×FTD são complementares, não redundantes: pizza mostra composição do todo, barras mostram eficiência comparada (budget% vs FTD%)
- Itirapina é um folder iCloud compartilhado — não rastreado pelo git, funciona como canal de sync assíncrono entre Darwin (Bira) e JP (Betinho)
- Prototype de dashboard é suficiente para alinhar direção com stakeholders, mas não substitui ferramenta operacional: faltam dados reais, period switcher funcional e nível de campanha
